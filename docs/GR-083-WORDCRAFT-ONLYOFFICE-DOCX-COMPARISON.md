# GR-083 — WordCraft and ONLYOFFICE DOCX comparison

**Bounded result: PASS for opening and byte-preservation checks; visual fidelity is partial.**
The test did not edit, save, or create Seafile versions. It is not project GPT approval,
production validation, or upstream authorization. Project GPT remains **INCOMPLETE** and
upstream publication remains **LOCKED**.

## Run

On 2026-11-04, a direct parent run used a disposable rootless Podman stack with synthetic
Seafile data. The WordCraft route opened the same three deterministic DOCX fixtures, then a
separate lab-only route configuration sent those same files to ONLYOFFICE. ONLYOFFICE remained
enabled; WOPI was disabled only in that disposable ONLYOFFICE comparison variant. The test
did not change the standard lab configuration, production Seafile, production ONLYOFFICE, or
any upstream repository.

Both variants opened all three files in the expected editor and reported a render-ready hint.
Seafile readback hashes before and after each open were identical to the fixture hashes. The
browser recorded no downloads. All six open/readback checks passed. The corrected ONLYOFFICE
run also recorded two HTTP 502 responses for its plugin and theme manifests; their cause is
NOT VERIFIED. The exact Seafile patch version was not recorded; the container image was tagged
`seafileltd/seafile-mc:13.0-latest`. The ONLYOFFICE image was tagged
`onlyoffice/documentserver:9.4`.
